## 设计系统核对

**字体与层级**

- 中文 UI 使用系统无衬线回退，标题、表格、状态标签和代码资源 ID 形成清晰层级。
- 页级标题、卡片标题、辅助说明和 11–13px 资源元数据在截图中均可区分，无意外换行或截断影响关键语义。

**布局与节奏**

- 保持被选方向的深石墨顶栏、浅色侧栏、约 200px 导航宽度和白色数据工作区。
- 首页、助手及密集表格页均使用一致 10px 圆角、细边框、克制阴影与 14–18px 间距；核心控制项未被遮挡。

**颜色与状态**

- 绿色只用于主操作、已通过和当前导航；黄、红、蓝分别承载待处理/拒绝/信息状态，未使用装饰性渐变。
- 草稿、可信、待审核、受阻、允许/拒绝在页面内有明确文字和颜色双重表达。

**图标与资产**

- 使用 Phosphor Icons 图标库；未用自制 SVG、emoji 或占位图替代界面图标。
- 本期为企业数据工作台，不需要照片、插画或品牌图片资产；空白处由实际表格、状态卡和资源详情承担信息密度。

**文案与产品约束**

- 页面统一强调 DatasetVersion、质量规则、Mapping、OntologyVersion、Policy 与 AgentToolInvocation 的资源链。
- 智能助手明确限定为已发布资源的受控工具调用，并说明不生成自由 SQL；敏感字段过滤和 Mock 显式标识均在对应页面出现。
